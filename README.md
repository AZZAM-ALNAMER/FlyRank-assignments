# FlyRank Internship Assignments

Weekly assignments from my AI Engineer Internship at [FlyRank](https://flyrank.ai) (July to October 2026), focused on backend development, APIs, and production-style AI services.

Each assignment lives on its own branch with its own README covering the task, my approach, and how to run the code.

## 🎓 Capstone

The final project is in a separate repository:

**[Usage Metering & Billing Engine](https://github.com/AZZAM-ALNAMER/flyrank-capstone-metering-billing)**: idempotent usage metering, plan quotas, AI-token pricing in integer micro-USD, and Stripe test-mode webhooks. Built with FastAPI and SQLite.
